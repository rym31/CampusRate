## Technologies

## Installation

git clone https://github.com/rym31/CampusRate.git
cd CampusRate
npm install

## Configuration

Copier .env.example vers .env et ajuster au besoin :

PORT=
DATA_FILE_PATH=

npm run start:dev

npm run build
